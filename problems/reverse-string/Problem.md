# Reverse String

## Description

Given a string `s`, return the string with its characters in reverse order.

## Examples

**Example 1:**
- Input: `s = "hello"`
- Output: `"olleh"`

**Example 2:**
- Input: `s = "a"`
- Output: `"a"`

**Example 3:**
- Input: `s = "racecar"`
- Output: `"racecar"`

**Example 4:**
- Input: `s = "Hello, World!"`
- Output: `"!dlroW ,olleH"`

## Constraints

- `0 <= s.length <= 1000`
- `s` consists of printable ASCII characters
