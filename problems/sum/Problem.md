# Sum from 1 to N

## Description

Given a positive integer `n`, return the sum of all integers from `1` to `n`, inclusive.

## Examples

**Example 1:**
- Input: `n = 5`
- Output: `15`
- Explanation: `1 + 2 + 3 + 4 + 5 = 15`

**Example 2:**
- Input: `n = 1`
- Output: `1`

**Example 3:**
- Input: `n = 10`
- Output: `55`

## Constraints

- `1 <= n <= 10000`
